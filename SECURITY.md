# Signaler un problème

Ne publiez pas de secrets ou de données personnelles dans une issue. Pour une faiblesse de sécurité, utilisez le signalement privé GitHub s’il est activé ; sinon ouvrez une issue demandant un canal privé sans détailler l’exploitation.

L’outil est conçu pour des données locales de confiance et sans privilèges administrateur. Les limites de sauvegarde sont décrites dans `docs/design.md`.
